# Capability: home

- **home.1** - an admin's `/admin` is Home; an editor's or author's goes to Posts *Since:* features/18b4a-review-apply-home
- **home.2** - Home lists the site's pages with Draft or Published and an Edit link *Since:* features/18b4a-review-apply-home
- **home.3** - after a draft is used and while nothing is published, Home says the website is ready, with the draft's page count *Since:* features/18b4a-review-apply-home
- **home.4** - while onboarding is offered, Home offers Start from a description, or Review your draft when the latest finished draft was never used *Since:* features/18b4a-review-apply-home
- **home.5** - while AI is on, Home shows this month's AI allowance as a percentage used and the date it renews, never credits or tokens *Since:* features/18b4a-review-apply-home
- **home.6** - a finished draft that no longer reads as a valid proposal is never offered as Review your draft *Since:* features/18b4a-review-apply-home
- **home.7** - while the website is ready, Home offers Publish website and a Preview that opens in a new tab *Since:* features/18b4b-preview-publish
- **home.8** - Publish website publishes every draft page of the site at once, no post, and Home then says the website is published with a link to it *Since:* features/18b4b-preview-publish
- **home.9** - Publish website changes nothing once anything on the site is published *Since:* features/18b4b-preview-publish
