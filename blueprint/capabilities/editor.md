# Capability: editor

- **editor.1** - a page or post is one document of 1-30 sections, each of 1-3 columns of blocks *Since:* features/14a1-the-document
- **editor.2** - text can be Text, Heading, Subheading or Small heading, a bulleted or numbered list, or a quote, with bold, italic and links *Since:* features/14a1-the-document
- **editor.3** - Undo and Redo cover every change, including adding, removing and re-columning sections *Since:* features/14a1-the-document
- **editor.4** - typing or deleting never merges or crosses sections and columns *Since:* features/14a1-the-document
- **editor.5** - a link outside the allowlist is refused beside the Web address field *Since:* features/14a1-the-document
- **editor.6** - a save over the size limit is refused with a message and the text stays in the editor *Since:* features/14a1-the-document
- **editor.7** - a page or post can hold an image chosen from Media, a button, a line and a space *Since:* features/14a2-image-button-line-and-space
- **editor.8** - focusing a palette tile and pressing Enter adds that block after the selected block, in its column *Since:* features/14a2-image-button-line-and-space
- **editor.9** - an image, a button or a section's settings are edited in a settings panel beside the canvas; text has none *Since:* features/14a2-image-button-line-and-space
- **editor.10** - a button links to a page, a web address or an email address, and an address outside the allowlist is refused beside its field *Since:* features/14a2-image-button-line-and-space
- **editor.11** - an image whose file was deleted shows "This image is no longer available." with Replace image *Since:* features/14a2-image-button-line-and-space
