# Capability: appearance

- **appearance.1** - Habre's admin and login follow the device's light or dark setting, in the warm stone and rust colours *Since:* features/13b-the-new-look
- **appearance.2** - text is set in Inter, served from the app's own origin; no font request goes to a third party *Since:* features/13b-the-new-look
- **appearance.3** - every colour pair in the admin and on the public site meets WCAG 2.2 AA contrast, proved by `e2e/contrast.spec.ts` *Since:* features/13b-the-new-look
- **appearance.4** - at 390px no admin or public screen scrolls sideways *Since:* features/13b-the-new-look
