# History: abandoned

Archive of items set aside before they were finished, named YYYY-MM-DD-title.md.

The `ship` skill writes here with `--abandon`. Each file is the spec as it stood,
ticks included, plus why it was abandoned and the branch that still holds its
code. The plan item stays unchecked. `spec` offers to resume from the archive
when the item comes up again.

Do not edit archived files by hand - the plan note and any resumed spec refer back
to them.
