# F-443 - Nothing stops a new browser module importing Zod directly and bringing the eval violation back on a screen the CSP test does not visit

**Found:** 2026-10-13 by review (scope: current; lens: tests)
**Why it matters:** the fix holds by discipline. Zod sits in the jitless chunk only because its importer sets match; a browser module importing `zod` directly splits it out, and the CSP spec only notices on the screens it visits (not account, reset-password, start-brand).
**Suggested fix:** a small build check that the client chunk containing Zod's `$constructor` also contains `jitless:!0`, or CSP browser checks for the unvisited screens.
