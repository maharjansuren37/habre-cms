# F-389 - The wait's action and Publish website still read a request body of any size

**Found:** 2026-10-08 by review (scope: current, second pass; lens: all)
**Why it matters:** F-382's problem in two more actions already on `main` (18b3-18b4b): any v1 signup is an admin, and nothing in Caddy limits request size, so one account can make the 954 MB server buffer a large body. OWASP Top 10:2025 A10.
**Suggested fix:** A small-limit guard (e.g. `isUserFormBodyAllowed`, 8 KB) before `formData()` in each, with a 413 test like F-382's.
