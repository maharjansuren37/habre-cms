# F-117 - The settings save reads a request body of any size

**File:** app/features/settings/settings.tsx:53-54
**Found:** 2026-09-29 by review (scope: full; lens: security)
**Why it matters:** Every other action that reads a body checks `Content-Length` first (login, users, entries, uploads - the F-01 rule, after three 100 MB bodies took the process past 1.5 GB). This one calls `request.formData()` with no bound, on a 954 MB server. It is admin-only and CSRF-checked, so reaching it needs an admin session. That is why this is P3: it closes a gap in a pattern that holds everywhere else, not an exposure to anonymous users. OWASP Top 10:2025 A10.
**Suggested fix:** Guard it the way `user-input.ts` does, with a settings-sized cap (20 navigation rows plus a title fit well under 16 KB) and a 413 before `formData()`. Add a unit test for the size check beside `settings-input.test.ts`.
