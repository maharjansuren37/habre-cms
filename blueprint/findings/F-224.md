# F-224 - The app role can write `schema_migrations`

**Found:** 2026-10-04 by review (scope: current; reviewer subagent, item 15a); lens: security - OWASP Top 10:2025 A02
**Why it matters:** SQL running as the app role could mark migrations applied or unapplied.
**Suggested fix:** As the owner, `revoke insert, update, delete on schema_migrations from habre_cms_app` - in `migrate.ts` after it creates the table, or in a migration (on a fresh database `roles.sql` runs before the table exists).
