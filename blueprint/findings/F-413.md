# F-413 - The plan page reads Stripe prices for a Launch site that shows none

**Found:** 2026-10-12 by review (scope: current; lens: performance, quality)
**Why it matters:** The loader's comment says "Only a Free site is offered a choice", but `billing.prices()` is called for any plan with billing on; `offer` is then null for a paid site. Cost is one Stripe read per ten minutes per process (a bounded 3 s wait once a minute while Stripe is down), but the comment and 21b's "Stripe calls only on a click" note disagree with the code.
**Suggested fix:** call `prices()` only when `canStartCheckout` is true (compute `offer`'s eligibility before the `Promise.all`).
