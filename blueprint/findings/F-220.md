# F-220 - Production instructions put the app-role password on the psql command line

**Found:** 2026-10-04 by review (scope: current; reviewer subagent, item 15a); lens: security - OWASP Top 10:2025 A02
**Why it matters:** `-v app_password=...` shows in the process list and the shell history on `ocwebserver`; `setup-server.sh`'s `run_roles_sql` avoids exactly this by using stdin.
**Suggested fix:** Document the stdin form: `{ printf "\\set app_password '%s'\n" "$PW"; cat roles.sql; } | sudo -u postgres psql -v ON_ERROR_STOP=1 -d habre_cms`.
