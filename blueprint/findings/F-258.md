# F-258 - Your account's card draws an empty divider above the Name section

**Found:** 2026-10-05 by review (item 15e1; scope: current; lens: every lens; reviewer subagent)
**Why it matters:** `.section` always draws `border-top` and `padding-top`; on Users edit a read-only row sits above the first section, here nothing does, so a line sits under the card's own top edge (seen in verify's screenshots, light and dark).
**Suggested fix:** `account.module.css` (the spec allows it) with `.section:first-child { border-top: 0; padding-top: 0; }`.
