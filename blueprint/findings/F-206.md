# F-206 - The top-level insertion position is computed twice, and `insertSection` throws for an index past the section count

**Found:** 2026-10-03 by review (scope: current; lens: every lens; item 14c2, reviewer subagent)
**Why it matters:** `sectionPos` (clamped) and `topLevelPosition` (unclamped) are the same loop; they can drift, and `insertSection` with `index > childCount` throws `RangeError` from `doc.child` instead of returning null. Unreachable from today's callers.
**Suggested fix:** Export one clamped helper from palette-insert.ts, use it in both, add a unit test for an out-of-range index.
