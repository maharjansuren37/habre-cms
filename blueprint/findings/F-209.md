# F-209 - The auto-scroll announcement tests do not check what is announced when scrolling stops

**Found:** 2026-10-04 by review (scope: current, main..03aa4a8, drag tidy fix; lens: every lens; reviewer subagent)
**Why it matters:** `last.t - stopped <= 600` passes when the last announcement came before scrolling stopped (negative), and `toHaveText(last.text)` compares the region with itself, so a place at the page's end never announced would pass.
**Suggested fix:** Assert `last.text` names the final place (its section number) and `last.t >= stopped - 300`.
