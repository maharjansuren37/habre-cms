# F-183 - The toolbar's tab stop is remembered by index across blocks and can land on Delete

**Found:** 2026-10-03 by review (independent `reviewer` agent; scope: current, 3044513..0bd787a, item 14a3; lens: all)
**Why it matters:** `active` is never reset when the kind changes: after Bold (index 4) on text, a selected line's Tab lands on "Delete line" (min(4, 2)), one Enter from deleting it.
**Suggested fix:** Reset `active` to 0 when block.pos or block.kind changes.
**Resolution:** Repaired 2026-10-03 (`block-toolbar.client.tsx`). Test `e2e/block-toolbar.spec.ts` "F-183: a newly selected block's toolbar starts at Move up…", written from this finding's reproduction: failed without the repair, passes with it. Closed by build (P3).
