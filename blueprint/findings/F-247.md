# F-247 - The reset form gives password managers no username to save the new password against

**Found:** 2026-10-04 by review (independent `reviewer` agent; scope: current, item 15c, main..083986a; lens: all)
**Why it matters:** The form has only a `new-password` field. Password managers may save the new password with no account, or keep the old saved one, so the next login autofills a stale password. Plausible; not checked in a browser.
**Suggested fix:** Return the email from `isResetTokenLive` and render it as a read-only `autocomplete="username"` field.
