# F-264 - The "two admins at once" test can pass without the site-row lock

**Found:** 2026-10-05 by review (scope: current; lens: every lens; via reviewer)
**Why it matters:** `click()` resolves when the click is sent. The poll turns true at the first commit, and `leftOfSite` reads while the second POST may still be in its transaction. An implementation with no lock (both deleted) could still pass, so the spec's "exactly one deleted" is not proven.
**Suggested fix:** set up two `waitForResponse` calls before the clicks and await both, then assert one page shows CHANGED, the other is at `/admin/login?deleted=1`, and `leftOfSite`.
