# F-239 - The signup error summary is not a list, and focus does not move to it

**Found:** 2026-10-04 by review (independent `reviewer` agent; scope: current, item 15b, b240716..46f4db2; lens: all)
**Why it matters:** Several errors render as `<span>`s in `Message`'s `<p>` where the semantic-HTML standard asks for `ul`/`li`; the mockup's summary takes focus (`tabindex="-1"`), this one does not, and without JavaScript a `role="alert"` present on load is generally not announced.
**Suggested fix:** Let `Message` take block children and render a `ul`; give the summary `tabIndex={-1}` and focus it when `actionData` changes (`autoFocus` for the no-JS case).
