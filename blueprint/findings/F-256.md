# F-256 - The old-address notice tells the reader to reply, which only helps if `EMAIL_FROM` is a monitored inbox

**Found:** 2026-10-05 by review (item 15e1; scope: current; lens: every lens; reviewer subagent)
**Why it matters:** After a confirmed change the old address can no longer use Forgot password, so this line is a hijacked account's only way back; Resend senders are often no-reply, and nothing records that `EMAIL_FROM` must be read by a person.
**Suggested fix:** Add the condition to the Resend line in `needs-you.md` (`EMAIL_FROM`, or a Reply-To, is a monitored inbox), or add an optional support address to the environment and name it in the text.
