# F-312 - A brand colour's links and outline buttons can fall to 4.48:1 on a band section

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** The derivation checks primary on bg, surface and subtle, never on `--color-surface-sunken` (#f5f5f5), the band section background the CTA template uses; 1,233 of 140,608 sampled sRGB colours land below 4.5 there (brand #69c369 -> #24822a, 4.478:1, reproduced). WCAG 2.2 1.4.3; breaks 18a1's goal.
**Suggested fix:** Add `sunken` to `BrandSurface` (light `#f5f5f5`, checked against app.css by the existing test) and require primary >= 4.5 on it in `shadesFor`; add `["primary", "surface-sunken", 4.5]` to `e2e/contrast.spec.ts`'s PAIRS; add the pair to design.md's derivation rule.
**Resolution:** Fixed by build (autopilot), 2026-10-07: `shadesFor` also requires primary >= 4.5 on `BrandSurface.sunken` (`#f5f5f5`, checked against app.css by the unit test). Test "a light green that already passed on white still reads at 4.5:1 on a band section" (`brand-colours.test.ts`): red with the repair reverted (9 pass, 1 fail), green with it (10 pass); `#69c369` now derives `#228128`, 4.54:1. `e2e/contrast.spec.ts` gains primary on surface-sunken, 11 passed. Awaiting re-review.
