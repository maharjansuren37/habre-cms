# F-316 - After a save, Settings' swatches keep the pre-save choice until a reload

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** The redirect to the same route keeps the component mounted, so `colourChoice`/`otherColour` are not re-derived: saving Other #2f6b5a shows a new unchecked "Saved colour #2f6b5a" beside a checked "Other colour", unlike a reload.
**Suggested fix:** Key the Brand section on the saved brandColor + stylePreset (or reset the state when they change); add the post-save check to `e2e/brand.spec.ts` without a reload.
