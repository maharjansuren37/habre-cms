# F-420 - The pre-warm can still be pointed at another address by changing DNS between the check and the request

**Found:** 2026-10-12 by review (scope: current; lens: every lens; independent reviewer pass)
**Why it matters:** The subset check uses the app's own resolver answer; `fetch` then resolves the domain again. Whoever controls the domain's DNS can answer with this server first and an internal address a moment later (zero TTL): a blind HTTPS HEAD to port 443 of any address, repeatable within the check limit. OWASP Top 10:2025 A01 (SSRF). Residual of F-414.
**Suggested fix:** Connect only to an address the check proved: a TLS handshake to one of the site's subdomain addresses with `servername: domain`, or a `fetch` dispatcher whose lookup returns only the site's set.
