# F-354 - The wait's live region is removed when the draft succeeds, so "Your draft is ready" is never announced

**Found:** 2026-10-07 by review (scope: current; lens: all; via reviewer)
**Why it matters:** Running and failed reuse a `<p role="status">` only because both put a `p` at the same index; the succeeded branch has none. WCAG 2.2 AA 4.1.3 Status Messages - the outcome the person waits for is silent.
**Suggested fix:** One persistent `role="status"` element outside the state branches, with text for each state.
