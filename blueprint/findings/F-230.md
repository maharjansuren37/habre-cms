# F-230 - The block toolbar can overhang a 390px viewport after a resize, failing the editor's stacking test

**Found:** 2026-10-04 by build (autopilot, item 15b step 7), while running the full browser suite
**Why it matters:** `e2e/document-editor.spec.ts:670` ("a 2-column section sits side by side in the canvas at 1280px and stacks at 390px") fails intermittently on `scrollWidth <= innerWidth`. A temporary probe showed `document.documentElement.scrollWidth` 398 at a 390px viewport, the only element past the edge being the block toolbar (`DIV._toolbar_…`, right edge 398). The toolbar is placed at the 1280px layout and is not always repositioned before the measurement once the viewport shrinks. Item 15b changes no editor code (`git diff main -- app/features/blocks app/app.css` is empty), and it failed in steps 1 and 6's full runs never, then in step 7's run and twice more here - so it is flaky, not new. A person rotating a tablet could see the page scroll sideways by a few pixels.
**Suggested fix:** `debug` first: confirm whether the toolbar repositions on resize (a `resize` listener or a `ResizeObserver` on the canvas) or only on selection change; then clamp the toolbar to the viewport, or have the test wait for the toolbar to settle if the overhang is transient.
