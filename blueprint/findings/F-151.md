# F-151 - A percent-encoded admin path (`/%61dmin/...`) may route to an admin screen while host routing, the CSP and the site scope see a public path

**Found:** 2026-10-02 by review (independent `reviewer` agent; scope: current, item 13b; lens: all)
**Why it matters:** React Router decodes the path for matching, but `areaForPath` and host routing read it raw - an admin screen could render on the public host under the public CSP. Cookie and origin checks limit the impact. Pre-dates 13b; not run (OWASP Top 10:2025 A01).
**Suggested fix:** Reproduce with `curl` on both hosts; if it routes, decode (or reject encoded) paths before `areaForPath` and host routing.
