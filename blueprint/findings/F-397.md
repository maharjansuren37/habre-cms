# F-397 - The post and home loaders' contact output has no browser test

**Found:** 2026-10-12 by review (scope: current; lens: every lens, by autopilot)
**Why it matters:** Step 3 wired `contactFor` into `page.tsx`, `post.tsx` and `home.tsx`, but `e2e/contact.spec.ts` only exercises `/:slug`. A broken post or home loader (no token, id on the wire) would not fail any test.
**Suggested fix:** Add one spec each: a post and the home page holding a contact block carry `entry` and `started`; the same without one carry neither.
**Resolution:** 2026-10-12, closed by build. Five tests added to e2e/contact.spec.ts (post and home, with and without a block; `/?contact=sent`). With `contactFor` made to return undefined, the three with-block tests went red (10 failed, 19 passed across contact specs); restored, 29 passed.
