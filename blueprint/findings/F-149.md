# F-149 - The production build polyfills `light-dark()`, so a `color-scheme` set outside Vite's CSS will not switch roles

**Found:** 2026-10-02 by review (independent `reviewer` agent; scope: current, item 13b; lens: all)
**Why it matters:** LightningCSS rewrites `light-dark()` as per-declaration toggles plus a prefers-color-scheme block. A `color-scheme` set in 18a's nonce'd inline `<style>` (D171) or from JS would switch in dev but not in production - affects items 14a, 18a, 20.
**Suggested fix:** When 18a or 20 sets a scheme outside the bundled CSS, prove it on `npm run build && npm start`; or configure Vite's CSS targets so `light-dark()` ships unpolyfilled.
