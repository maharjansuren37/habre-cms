# F-396 - Contact browser tests depend on JWT_SECRET in the test process

**Found:** 2026-10-12 by review (scope: current; lens: tests)
**Why it matters:** The spec mints tokens with process.env.JWT_SECRET (empty string fallback). Local runs passed; CI sets it through GITHUB_ENV, but no CI run of this branch exists, so a mismatch would show as every valid-token case failing there.
**Suggested fix:** confirm on the first CI run; if it is empty there, have playwright.config.ts export the secret it gives the server.
