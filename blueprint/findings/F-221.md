# F-221 - The documented by-hand run of CI's `e2e` job fails at the new roles step

**Found:** 2026-10-04 by review (scope: current; reviewer subagent, item 15a); lens: docs
**Why it matters:** `init.sh` is fed through `sh -s`, so `$0` is `sh` and `ROLES_SQL` resolves to `./../roles.sql`, absent in the container; the app role is never made. CI itself works (`$0` is the script path).
**Suggested fix:** `docker cp db/roles.sql ci-db:/roles.sql` first and add `-e HABRE_ROLES_SQL=/roles.sql` to the `docker exec`.
