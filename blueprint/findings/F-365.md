# F-365 - Home trusts status 'succeeded' without the parse rule: an unreadable draft is offered as waiting, and an unreadable applied draft reads "We drafted 0 pages"

**Found:** 2026-10-08 by review (scope: current; lens: all; via reviewer)
**Why it matters:** runView treats an unparseable succeeded run as failed invalid; Home's findLatestFinishedRun and appliedRunPageCount do not, so Review your draft opens Couldn't build, and the ready panel can say 0 pages. Reachable after a schema tightening or a failed retry.
**Suggested fix:** Return only a parsing succeeded row from findLatestFinishedRun (or pass resultParses to homeState); count from the menu's page ids, or hide the sentence at 0.
