# F-235 - `SMTP_URL`'s query string can switch off TLS checks, getting round the never-in-clear rule

**Found:** 2026-10-04 by review (independent `reviewer` agent; scope: current, item 15b, b240716..46f4db2; lens: all)
**Why it matters:** nodemailer applies URL query keys as options and the env rule accepts them: `smtps://host?tls.rejectUnauthorized=false` and `?ignoreTLS=true` pass (checked against nodemailer 10.0.14), letting a middle-man read sign-in links. Operator-controlled, but the rule exists to stop exactly this.
**Suggested fix:** Refuse an `SMTP_URL` with a non-empty query string (or any `tls.*`, `ignoreTLS`, `secure` key).
