# F-223 - The web process is given the owner's database credentials

**Found:** 2026-10-04 by review (scope: current; reviewer subagent, item 15a); lens: security - OWASP Top 10:2025 A02
**Why it matters:** Both URLs go into `production.env`, which the systemd unit loads for the app, so a compromised app process holds a role that bypasses row-level security and can change the schema - weakening D152.
**Suggested fix:** Keep `DATABASE_OWNER_URL` in a separate root-only file (e.g. `/etc/habre-cms/migrate.env`) that only the migrate command reads.
