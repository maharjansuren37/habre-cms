# F-350 - The SDKs still read some settings from the environment, and the F-347 comment says they are all pinned

**Found:** 2026-10-07 by review (scope: current, ec70ea9, fingerprint 8a0aebc967fa; lens: every lens; via reviewer)
**Why it matters:** `OPENAI_ORG_ID` / `OPENAI_PROJECT_ID` reach both OpenAI-SDK clients (openai/client.js:183), and a stray project id makes OpenAI direct 401 - `broken`, no fallback. `ANTHROPIC_CUSTOM_HEADERS` / `OPENAI_CUSTOM_HEADERS` add headers to every request, merged after the auth headers in the Anthropic SDK. Operator-only, like F-347; the comment in `client-options.ts` claims every setting is pinned.
**Suggested fix:** Pass `organization: null, project: null` in `openAIClientOptions` and `openRouterClientOptions`; refuse startup when either `*_CUSTOM_HEADERS` is set, or reword the comment to name what is not pinned. Cover both in `client-options.test.ts`.
