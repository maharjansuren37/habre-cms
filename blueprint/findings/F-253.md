# F-253 - Your account's forms keep what was typed after a successful save, including both passwords

**Found:** 2026-10-05 by review (item 15e1; scope: current; lens: every lens; reviewer subagent)
**Why it matters:** The action redirects to the same route, so the uncontrolled inputs stay mounted: verify's screenshot after "link sent" shows New email and Current password still filled. Secrets stay in the DOM on a shared screen, and pressing Save again sends an old password that now counts against `emailLoginLimiter` (OWASP Top 10:2025 A07). `user-edit.tsx`'s reset form has the same shape.
**Suggested fix:** Remount each `Form` after a save (a `key` from `savedMessage` or `location.key`), or reset it when navigation returns to idle with no `actionData`.
