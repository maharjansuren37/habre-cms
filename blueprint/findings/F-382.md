# F-382 - Make it yours reads a request body of any size before checking it

**Found:** 2026-10-08 by review (scope: current; lens: all)
**Why it matters:** Settings caps the same three fields at 16 KB (`isSettingsFormBodyAllowed`, F-01/F-117), but step 3's action calls `request.formData()` unchecked. In v1 every signup is an admin of their own site, so any account can make the 954 MB server buffer a large body. OWASP Top 10:2025 A10.
**Suggested fix:** Return 413 when `isSettingsFormBodyAllowed(request.headers)` fails, before `formData()`; guard `start-about.tsx`'s action the same way.
