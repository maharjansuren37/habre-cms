# F-267 - Known gap: delete in one tab while demoting the only other admin can leave a site with no admin, and then a memberless site

**Found:** 2026-10-05 by review (scope: current; lens: every lens; via reviewer)
**Why it matters:** This is the spec's accepted residual race (Notes): role changes and deactivation never take the site-row lock or check for the last admin. The review confirmed it is the only path to an admin-less site. One more consequence: such a site falls to the leave case for everyone, so its members can all leave, leaving a site row with no members that keeps its subdomain and content, with no way to delete it.
**Suggested fix:** a "last active admin" guard on Users' role change and deactivate, taking the site-row lock. That is its own item.
