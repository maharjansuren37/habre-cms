# F-204 - Screen readers may read the editor's empty-text hints as content

**Found:** 2026-10-03 by review (independent `reviewer` agent; scope: current, item 14c1, 8b39d6c..938e4a1; lens: all)
**Why it matters:** Chromium and WebKit expose CSS `::before` text to assistive technology. Before this item only an empty document had a hint; now many blocks do ("Main heading", "Text"). The spec's "not read as content" may be wrong. Code reading only - nothing rendered or heard.
**Suggested fix:** `content: attr(data-placeholder) / "";` on both rules (empty alt text for generated content); confirm in the screen-reader pass in needs-you.md.
