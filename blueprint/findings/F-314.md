# F-314 - Other colour saves the wrong colour before hydration or without JavaScript

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** The colour picker has no `name` and the Other radio's value only follows React state, so a colour picked before hydration is silently replaced by the saved colour or #2f6b5a on Save.
**Suggested fix:** Name the picker (e.g. `brandColorOther`) and let the action use it when the Other radio is chosen, or keep the Other radio disabled until hydration.
