# F-400 - No browser test measures contrast with a site's dark mode on

**Found:** 2026-10-12 by review (scope: current; lens: accessibility)
**Why it matters:** the dark site scope and dark brand shades are held by unit tests (`brand-colours.test.ts`) and a background check (`levels.spec.ts`), but `contrast.spec.ts` still measures only the light site under a dark device, so a role missed in the dark block would not fail anything.
**Suggested fix:** run `contrast.spec.ts`'s site pairs once more on a site with `dark_mode` on under a dark device.
