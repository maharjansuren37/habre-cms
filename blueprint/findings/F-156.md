# F-156 - A link with mixed formatting renders as several adjacent links

**Found:** 2026-10-02 by review (independent `reviewer` agent; scope: current, item 14a1; lens: all)
**Why it matters:** TipTap splits text nodes where marks change, so a link with a bold middle word becomes three `<a>` with one href: three tab stops and three announcements.
**Suggested fix:** Group consecutive text nodes sharing a link href into one `<a>`, nesting strong/em inside.
