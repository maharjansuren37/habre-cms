# F-442 - The jitless comment says the server keeps the fast path and that every schema-building browser module imports it; neither is quite true

**Found:** 2026-10-13 by review (scope: current; lens: quality)
**Why it matters:** only the app server keeps the compiled path - `scripts/create-admin.ts` and `node --test` now run jitless via `user-input.ts`. `contact-message.ts` builds a schema in browser code without the import and is covered only because `settings-input.ts` imports jitless before it; a future browser importer of it would bypass that.
**Suggested fix:** say "the app server", and name `contact-message.ts` as covered through `settings-input.ts` - or add the import to `contact-message.ts` too.
