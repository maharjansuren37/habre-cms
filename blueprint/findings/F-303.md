# F-303 - optimise-media needs the whole web-app environment, not only DATABASE_URL

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** It imports `r2.server.ts`, which loads `env.server.ts`, so it fails at import without `JWT_SECRET`, `PLATFORM_URL`, `SITES_URL`, every `R2_*`, and email settings when signup is on. AGENTS.md says the operator commands need `DATABASE_URL`.
**Suggested fix:** Say in AGENTS.md *Commands* that it needs the app's full environment (production: `/etc/habre-cms/production.env`), or give R2 its own env parse.
