# F-140 - The F-95 note vanishes after any add/move/remove, and is not tied to its select

**Found:** 2026-10-02 by review (independent `reviewer` agent; scope: current, tidy-findings; lens: all)
**Why it matters:** The select's `defaultValue` matches no option, so the browser submits `""`; after a nav round trip the row silently reads "No page". Screen-reader users tabbing to the select do not hear the note (WCAG 2.2 1.3.1, 3.3.1).
**Suggested fix:** Render `<option value={row.pageId}>(deleted page)</option>` when the page is missing, and link the note with `aria-describedby` as the home page hint already is.
