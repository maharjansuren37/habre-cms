# F-359 - The host-split Playwright server pins only `OPENROUTER_API_KEY=`, not `AI_PROVIDERS=`

**Found:** 2026-10-07 by review (scope: current; lens: all; via reviewer)
**Why it matters:** A local `.env` with `AI_PROVIDERS=fake` turns AI on there (PLATFORM_URL is 127.0.0.1), or one listing a direct provider first stops startup; the AI-off test then fails locally, never in CI.
**Suggested fix:** Also pin `AI_PROVIDERS=` on that command.
