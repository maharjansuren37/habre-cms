# F-412 - A trial cancelled in the Portal still reads "Then billed monthly"

**Found:** 2026-10-12 by review (scope: current; lens: quality)
**Why it matters:** A trialing subscription set to cancel at period end is `plan: paid`, `billing_status: canceled` with `trial_ends_at` set (`billing-events.ts`). `planNotice` tests `trialEndsAt` first, so the page says "Then billed monthly. Cancel any time before then" for a subscription that will not bill, and never reaches "Launch until ... will not renew".
**Suggested fix:** in `planNotice`, check `billingStatus === "canceled"` before the trial branch (or give the trial branch a cancelled variant), with a unit case in `billing-view.test.ts` / `plan-view` tests.
