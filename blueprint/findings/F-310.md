# F-310 - sharp's prebuilt x64 binary needs x86-64-v2, which the server is not checked for

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** `setup-server.sh` checks only `uname -m`; a CPU without x86-64-v2 would fail to load sharp at startup.
**Suggested fix:** Check `/proc/cpuinfo` flags (sse4_2, popcnt) on `ocwebserver`, and add the check to the script.
