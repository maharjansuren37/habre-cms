# F-392 - The AI swatch's hex sits off-centre under its dot now that "Suggested by AI" is under it

**Found:** 2026-10-08 by review (scope: current; lens: accessibility/design; via reviewer)
**Why it matters:** `.swatch` centres `.swatchName` as a grid item as wide as "Suggested by AI"; the hex line inside it is left-aligned, so it sits left of the centred dot (seen in the Step 3 1280px screenshot). Visual only, not a WCAG failure.
**Suggested fix:** `text-align: center` on `.swatchName` in `brand-fields.module.css`; one-line swatch names are unaffected.
