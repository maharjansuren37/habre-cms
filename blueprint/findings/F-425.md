# F-425 - A platform host with no `app.` label would reserve its public suffix

**Found:** 2026-10-12 by review (scope: current; lens: quality)
**Why it matters:** `platformParent` drops the first label of any host with 3+ labels. D153 makes the platform `app.<domain>`, so it holds today, but an apex platform on a three-label domain (`habre.com.au`) would reserve `com.au` and refuse every `.com.au` own domain. Not confirmed: no such deployment exists.
**Suggested fix:** Only derive a parent when the first label is `app`, or when the platform host is a subdomain of a configured platform domain.
