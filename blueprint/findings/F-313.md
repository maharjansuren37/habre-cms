# F-313 - deriveBrandShades only darkens, so a dark surface silently gets failing shades

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** The spec makes `deriveBrandShades(hex, surface)` load-bearing for item 20's dark call, but on `{bg:#0a0a0a, surface:#171717}` it returns #000000 at 1.06:1 with no signal - the loop only lowers lightness and drops `ok`.
**Suggested fix:** Throw when the loop exhausts without `ok` (unit test it), and narrow the parameter to the light surface or record in the spec/design.md that item 20 needs a lightening direction and its own hover/subtle rule.
