# F-418 - 'Not found yet' is an error banner, and the page changes itself every 15 s with no announcement or pause

**Found:** 2026-10-12 by review (scope: current; lens: every lens)
**Why it matters:** An expected waiting state is red like a failure; and the section turns to 'verified' on its own with nothing announced to a screen reader. WCAG 2.2: 4.1.3 Status Messages, 2.2.2 Pause, Stop, Hide.
**Suggested fix:** Use a neutral tone for no-txt and not-pointing, give the section a polite live region, and offer a way to stop the refresh (or refresh only on focus).
