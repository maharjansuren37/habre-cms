# F-181 - The Text style menu can open with no item focused and then not close from the keyboard

**Found:** 2026-10-03 by review (independent `reviewer` agent; scope: current, 3044513..0bd787a, item 14a3; lens: all)
**Why it matters:** On a page, a range selection with its head in the main heading hides Main heading (offerMain false) while the button reads "Main heading": no item is checked, focus stays on the button, and Escape or Tab leave the menu open (WCAG 2.2 2.1.1, 2.4.3).
**Suggested fix:** Focus the first item when none is checked, and close the menu from the toolbar's Escape handler.
**Resolution:** Repaired 2026-10-03 (`block-toolbar.client.tsx`). Test `e2e/block-toolbar.spec.ts` "F-181: with no style checked, the menu still opens on an item…", written from this finding's reproduction: failed without the repair, passes with it. Closed by build (P3).
