# F-120 - A page editor opened before the deploy cannot save, and its message says nothing to do

**File:** app/features/blocks/blocks.ts:`fromEditorJsSections` (`UNREADABLE_SHAPE`); app/features/content/entry-form.tsx (problem message)
**Found:** 2026-10-01 by review (scope: current; lens: quality)
**Why it matters:** A tab left open on a page editor from before this release still submits the flat `{ blocks }` shape. The server now refuses it with "The editor sent content in a shape this version cannot read." - which, under "Your changes were not saved.", does not say to reload, and what was typed is lost unless copied. Rare (only the deploy window), and the refusal itself is the right behaviour.
**Suggested fix:** For the flat-shape case return a sentence that says what to do, e.g. "This page editor is from an older version of the site. Copy your changes, reload, and paste them in."
**Resolution:** fixed 2026-10-01. Flat `{ blocks }` now answers "older version of the site. Copy your changes, reload, and paste them in."; `entry-input.test.ts` updated. `npm run verify` passes.
