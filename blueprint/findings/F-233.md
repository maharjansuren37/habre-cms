# F-233 - Turning signup off strands unconfirmed accounts: login sends them to a 404

**Found:** 2026-10-04 by review (independent `reviewer` agent; scope: current, item 15b, b240716..46f4db2; lens: all)
**Why it matters:** `/signup/sent` and `/verify` answer 404 when `SIGNUP_MODE=off`, but login still redirects an unconfirmed user to `/signup/sent`. Closing the beta (mode back to `off`) would leave pending people on Not Found and kill their emailed links. The spec asks only `/signup` to 404.
**Suggested fix:** Gate only `/signup` on the mode; keep `/verify` always on and gate resend on email being configured - or have login refuse with a message while the mode is off.
