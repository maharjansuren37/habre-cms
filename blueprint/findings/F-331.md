# F-331 - The description can still close its own fence

**Found:** 2026-10-07 by review (scope: current; lens: every lens; via reviewer)
**Why it matters:** `replaceAll(">>>", "> > >")` replaces non-overlapping matches, so `>>>>>` becomes `> > >>>` and still holds the closing token; the comment and test claim otherwise. Low impact: the writer only steers their own proposal, and both gates still validate it.
**Suggested fix:** `description.replace(/[<>]{3,}/g, (m) => [...m].join(" "))` and add `>>>>>` / `<<<<<` to the test.
