# F-309 - Peak memory resizing a 40-megapixel image on the 954 MB server is unmeasured

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** The 552 MB peak was a synthetic 24 MP JPEG in a process that also made the input. A 40 MP PNG rotated 90 degrees (no shrink-on-load) beside Node and Postgres could approach OOM.
**Suggested fix:** Measure a ~40 MP PNG with orientation 6 in a fresh process before the v1 deploy; lower the cap if it is too close.
