# F-338 - The ai-runs browser spec can fail when the site-isolation sweep test runs alongside it

**Found:** 2026-10-07 by review (scope: 5855b1d..HEAD; lens: every lens; via reviewer)
**Why it matters:** With `workers: 2` the files interleave; `fail_interrupted_ai_runs()` fails every `running` row on every site, so if it lands between the fresh-row insert and the child query (~150-200 ms) the test gets `false` instead of `true`.
**Suggested fix:** Run the two specs serially with respect to each other, or insert and query inside the same child process.
