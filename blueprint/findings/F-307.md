# F-307 - media-optimise.spec leaves R2 objects behind when it fails partway

**Found:** 2026-10-07 by review (scope: current; every lens; via reviewer)
**Why it matters:** `deleteSite` removes rows only; a failure before the test's own delete leaves objects in the dev bucket, which is production's too (needs-you, risk accepted). Other R2 specs share the pattern.
**Suggested fix:** In `afterEach`, delete `mediaObjectKeys` for the site's rows before `deleteSite`.
