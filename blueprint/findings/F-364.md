# F-364 - The review badges the first page "Home page", but Use this draft makes p1 the home page

**Found:** 2026-10-08 by review (scope: current; lens: all; via reviewer)
**Why it matters:** proposalSchema does not require p1 first. A proposal ordered [p2, p1] shows p2 as Home page in the review while apply sets home_page_id to p1 - what is applied is not what was reviewed.
**Suggested fix:** Expose homeKey from reviewSummary via one helper shared with planApply and badge that page; unit case with pages [p2, p1].
**Resolution:** fixed by build (18b4a Step 9, 2834970): `homePageKey` shared by `planApply` and `reviewSummary`; the review badges `review.homeKey`. Tests in apply-plan.test.ts ([p2, p1] and no p1) failed first on `undefined !== 'p1'`, pass after (16/16).
