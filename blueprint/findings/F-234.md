# F-234 - An email send failure is logged with no cause

**Found:** 2026-10-04 by review (independent `reviewer` agent; scope: current, item 15b, b240716..46f4db2; lens: all)
**Why it matters:** `catch {}` / `.catch(() => ...)` drops the nodemailer error, so a Resend problem in production (auth, TLS, DNS, the daily cap) shows only as `email_send_failed`, with nothing to diagnose it from.
**Suggested fix:** Log the error's `code`, `responseCode` and `command` - never `message`, which can echo the recipient.
