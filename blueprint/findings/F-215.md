# F-215 - Older unit tests compare a Transaction to null with `assert.equal`, which exhausts memory when one fails

**Found:** 2026-10-04 by review (scope: current, main..03aa4a8, drag tidy fix; lens: every lens; reviewer subagent)
**Why it matters:** A failing `equal(tr, null)` makes node:test render a whole ProseMirror Transaction; memory reached about 30 GB in this session and took the session down. Pre-existing; only the new tests use the safe form.
**Suggested fix:** `assert.ok(x === null, "...")`, or an `outcome()`-style helper as the new block-drops tests use.
