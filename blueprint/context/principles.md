# Principles

> The project's non-negotiable commitments. `review` and `preflight` audit
> against this file.

Stated by the owner during `ideate --rescope`, 2026-10-01 (D148).

- **Simple by default, powerful when needed.** A beginner never sees content
  schemas, API versions, webhooks, JSON or role matrices unless they switch them
  on. Power is added by revealing more, never by making the default screen
  busier.
- **AI suggests, the user applies.** AI never changes a site's published
  content without the user reviewing and applying the change. Generated drafts
  are drafts until a person publishes them.
